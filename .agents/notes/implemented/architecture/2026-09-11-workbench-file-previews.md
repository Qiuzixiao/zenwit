# Workbench document previews

The common workbench owns file presentation independently of Agent workflows and deleted DSH page shells. Original PDF worker/rendering and HTML sandbox utilities live under its preview components. Tabs choose a reader or editor by file type; HTML/SVG previews consume the current draft, and binary tabs never enter text persistence.

The generic Host returns bounded raw bytes as attachments with a sandbox CSP. Related resources remain within the source project and use the same origin and symlink checks as other project operations. Text endpoints reject binary content before recovery or replacement. HTML reads a finite static set of classic JS, CSS and image resources; ES module graphs, CSS dependency graphs and runtime requests require a development server.

Regression coverage includes original language suffixes, unsaved preview switching, binary write rejection, cross-project related-file rejection, PDF worker disposal, HTML packaging, and real browser rendering through the product composition.
